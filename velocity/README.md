
# Как создать Velocity-сервер?

1. Создайте папку `velocity` в папке с вашей сборкой.
2. Загрузите ядро по [ссылке](https://fill-ui.papermc.io/projects/velocity/version/3.2.0-SNAPSHOT) и добавьте в папку `velocity`.
3. Установите все плагины по [инструкции](plugins).
4. Переместите все папки и файлы из этого раздела в папку `velocity`.
5. Переименуйте файл ядра в `Velocity.jar`.
6. Можно запускать [`start.bat`](start.bat) (для Windows) или [`start.sh`](start.sh) (для Linux).
