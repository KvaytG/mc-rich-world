
# Как создать сервер Ямы?

1. Создайте папку `pit` в папке с вашей сборкой.
2. Загрузите ядро по [ссылке](https://github.com/PatinaMC/Patina) (версия 1.16.5) и добавьте в папку `pit`.
3. Установите все плагины по [инструкции](plugins).
4. Переместите все папки и файлы из этого раздела в папку `pit`.
5. Переименуйте файл ядра в `Patina-1.16.5.jar`.
6. Загрузите мир по [ссылке](https://www.planetminecraft.com/project/1-16-5-the-pit-download/) и переименуйте его в `world`.
7. Можно запускать [`start.bat`](start.bat) (для Windows) или [`start.sh`](start.sh) (для Linux).
