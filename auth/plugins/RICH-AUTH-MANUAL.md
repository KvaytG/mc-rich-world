
# Как подключить Telegram-бота к плагину RichAuth?

1. **Откройте Telegram на любом устройстве.**
2. **Найдите `@BotFather`.** В поиске введите `@BotFather` (официальный бот для создания ботов) → выберите его из списка → нажмите START.
3. **Создайте нового бота.** Отправьте команду: `/newbot`.
4. **Укажите параметры:** Имя бота (отображается в контактах), например: «RichWorld бот», а так же юзернейм бота (он должен оканчиваться на "bot"), например: «RichWorldMcBot».
5. **Получите токен.** После подтверждения BotFather пришлет сообщение с токеном вашего бота.
6. **Скопируйте токен.** Выделите и сохраните строку токена (начинается с цифр, содержит двоеточие и буквенно-цифровые символы).
7. **Откройте файл конфигурации в папке плагина RichAuth и впишите свой токен в поле `bot-token`.**
8. **Не забудьте так же поменять поле `bot-username` на юзернейм вашего бота.**
