
# Как создать сервер авторизации?

1. Создайте папку `auth` в папке с вашей сборкой.
2. Загрузите ядро по [ссылке](https://github.com/PatinaMC/Patina) (версия 1.16.5) и добавьте в папку `auth`.
3. Установите все плагины по [инструкции](plugins).
4. Переместите все папки и файлы из этого раздела в папку `auth`.
5. Переименуйте файл ядра в `Patina-1.16.5.jar`.
6. Можно запускать [`start.bat`](start.bat) (для Windows) или [`start.sh`](start.sh) (для Linux).
