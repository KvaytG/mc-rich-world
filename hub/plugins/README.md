
# Плагины для сервера Хаба

1. Создайте папку `plugins` в папке с Patina-сервером.
2. Скомпилируйте следующие плагины:

    * [ColorAPI](/.plugins-src/ColorAPI)
    * [CommandLimiter](/.plugins-src/CommandLimiter)
    * [RichChat](/.plugins-src/RichChat)
    * [RichDonate](/.plugins-src/RichDonate)
    * [RichHub](/.plugins-src/RichHub)
    * [RichMobs](/.plugins-src/RichMobs)
    * [RichWorld](/.plugins-src/RichWorld)

   и положите в папку `plugins`.
3. Скачайте следующие плагины:

    * [DeluxeMenus](https://www.spigotmc.org/resources/deluxemenus.11734/)
    * [NoCheatPlus](https://ci.codemc.io/job/Updated-NoCheatPlus/job/Updated-NoCheatPlus/)
    * [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/)
    * [TAB](https://www.spigotmc.org/resources/tab.57806/)
    * [ZNPCsPlus](https://www.spigotmc.org/resources/znpcsplus.109380/)

   и положите в папку `plugins`.
4. Переместите папки плагинов (их настройки) из текущей директории в папку `plugins`.
