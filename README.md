# 💛 RichWorld

RichWorld — готовая экосистема с кросс-серверной экономикой.

## 🌟 В чём уникальность?

* Единая кросс-серверная экономика: зарабатывайте монетки в любом режиме и тратьте их где угодно;
* Уникальная авторизация через Telegram: забудьте о /reg и /login! Безопасный и удобный вход через Telegram-бота;
* Донат-система: всего одна, но мощная VIP-привилегия. Еë можно купить за 5000 игровых монеток, что стимулирует внутриигровую экономику;
* Оптимизированная самописная основа: плагин RichWorld — высокопроизводительное сердце системы, отвечающее за спавн, предметы, перки, ограничения миров, варпы и многое другое;
* Готовая монетизация: встроенная система выдачи статусов (/status) и монеток (/coins) через консоль Velocity. Легко подключить RCON для реализации донат-магазина.

## 🛠 Из чего состоит проект?

* Сервер Авторизации (Auth): основа безопасности. Вход только через Telegram-бота. Нет стандартных команд регистрации/логина;
* Сервер Хаба (Hub): центральное место сбора игроков. Уникальная карта ручной постройки. Отсюда игроки выбирают режимы, а ещё на спавне можно поубивать свинок за монетки;
* Режим «Яма» (Pit): Динамичный PvP-режим по мотивам Hypixel. Игроки сражаются на открытой арене, зарабатывают монетки за убийства и прокачивают экипировку;
* Режим «Симулятор» (Simulator): Уникальная PvE-гриндилка! Сбор травы, охота на слаймов, торговля с NPC за монетки. Расслабленный геймплей для любителей пофармить;
* Режим «Анархия» (Anarchy): Классическое хардкорное выживание без правил (а-ля 2B2T). Монетки зарабатываются продажей ресурсов и тратятся на зелья.

## 📋 Каковы требования к запуску?

Проект технически завершён, сборка полностью рабочая и готова к развёртыванию на вашем хостинге.

1. Требуется Java 16.
2. Для комфортной игры на хостинге нужно около 16Гб ОЗУ, но для запуска локально подойдёт и 8Гб.
3. Открытые порты: 25565, 28000, 28001, 28002, 28003 и 28004.

## 🚀 Как собрать и запустить?

1. Создайте Velocity-сервер по [инструкции](velocity).
2. Создайте сервер авторизации по [инструкции](auth).
3. Создайте сервер Хаба по [инструкции](hub).
4. Создайте сервер Симулятора по [инструкции](simulator).
5. Создайте сервер Ямы по [инструкции](pit).
6. Создайте сервер Анархии по [инструкции](anarchy).
7. Запустите лаунчер: [`start.bat`](start.bat) (для Windows) или [`start.sh`](start.sh) (для Linux) — если сервера ещё не запущены.
